# ESP32-S3-EYE 外壳 · 结构 · 载板 PCB 设计方案

> **这份文档是什么**
>
> 第 2 周的远程采集功能已经跑通，但板子一直是"裸奔"状态：排针外露、USB 线一碰就掉、
> 摄像头没有固定、脱机用充电宝时无处安放。本文档给出**可直接拿去打样/打印**的
> 外壳、结构与载板 PCB 设计方案。
>
> **边界声明（先说清楚，避免误解）**
>
> 本仓库提供的是**设计参数、2D 图纸（SVG）、物料清单、装配顺序与验证清单** ——
> 这些是设计本身。**不含 STEP / STL 等 3D 模型文件**，原因是本环境不具备 3D 建模能力；
> 需要 3D 模型时，请按本文档 §2 的参数表与 §4/§5 的图纸在 CAD 里建模
> （SolidWorks / Fusion 360 / FreeCAD 均可，参数已给全，建模是"照着抄尺寸"的工作量）。
> 本文档刻意不假装交付了 3D 文件。

## 一、设计输入：哪些是事实，哪些必须实测

设计机械件最忌讳拿"看起来差不多"的尺寸去开模。所以先把输入分成两类：

### 1.1 已确认事实（来源：乐鑫官方板卡管理指南 · ESP32-S3-EYE v2.2）

| 项目 | 内容 |
|---|---|
| 核心模组 | ESP32-S3-WROOM-1（内含 ESP32-S3R8，**8 MB Octal PSRAM + 8 MB Flash**） |
| 摄像头 | OV2640，200 万像素，**视角 66.5°**，最高 1600×1200 |
| 加速度计 | QMA7981，**仅三轴加速度，无陀螺仪** |
| 麦克风 | MEMS 数字麦 ×1，I2S 接口，灵敏度 −26 dBFS，SNR 61 dB |
| 功能按键 | **6 个**（其中 RST 不可配置，5 个可配置） |
| LCD | **1.3 英寸**，SPI 接口，位于**子板 ESP32-S3-EYE-SUB** 上 |
| 存储 | MicroSD 卡槽 ×1 |
| USB | **Micro-USB**，兼作 5 V 供电与通信，走 GPIO19/20 |
| 电池 | 电池焊点 + 充电芯片 ME4054BM5G-N（1 A 线性充电）；建议 >1000 mAh / 3.7 V |
| 结构 | **主板 MB + 子板 SUB 两块**，通过排针/排母 + FPC 排线连接，出厂已组装 |
| 指示灯 | 模组电源灯（绿，GPIO3，**必须开漏驱动**）；电池充电红灯 |

### 1.2 必须实测确认的尺寸（图纸中一律标 ★）

乐鑫**没有在网页上公布毫米级外形尺寸**，只在官方文档的「尺寸图」小节提供
PDF / DXF 下载（主板正面/背面、子板各一份）。因此以下参数**必须**从尺寸图或卡尺实测取得：

| 参数 | 符号 | 图纸中的示例值 | 状态 |
|---|---|---|---|
| 主板外形 长 × 宽 | `Lmb × Wmb` | 45.0 × 35.0 ★ | **待实测** |
| 子板外形 长 × 宽 | `Lsb × Wsb` | 45.0 × 25.0 ★ | **待实测** |
| 板厚 | `t_pcb` | 1.6 ★ | **待实测** |
| 安装孔孔径 / 孔距 | `d_hole / p_hole` | Ø2.7 / 孔距待测 ★ | **待实测** |
| 摄像头模组外形高度 | `h_cam` | 6.0 ★ | **待实测** |
| 摄像头镜头光心到板边距离 | `x_lens` | 待测 ★ | **待实测** |
| LCD 模组外形高度 | `h_lcd` | 3.2 ★ | **待实测** |

> **工作方法**：先量这 7 个数，再改图纸里的 ★ 值，然后才打样。
> 图纸里所有非 ★ 的数值（壁厚、间隙、圆角、开孔余量）都是**设计给定值**，可以直接用 ——
> 它们只取决于工艺，不取决于板子。

## 二、设计目标与约束

### 2.1 目标（按优先级）

1. **保护摄像头与排针**，同时**完全不遮挡 66.5° 视场**；
2. **Micro-USB 可随时插拔**（烧录/串口是高频操作，不能每次拆壳）；
3. **SD 卡可随时插拔**（导出图像）；
4. **支持脱机运行**：可接电池/充电宝，底面留三脚架螺纹孔，方便固定拍摄角度；
5. **可反复拆装**（课堂上要拆给学生看），不用胶水、不用一次性卡扣。

### 2.2 硬约束（不可协商）

| # | 约束 | 原因 |
|---|---|---|
| C1 | **子板与主板必须同平面并排，不得上下叠放** | 叠放时 LCD 正好压在摄像头正上方，直接挡住视场 |
| C2 | **上盖必须做台阶**：摄像头段高、LCD 段低 | 两处高度差 2.8 mm；不做台阶整机白高 2.8 mm |
| C3 | **所有开孔开在盖板上，不在侧壁上** | 侧壁开孔会切断卡扣根部，反复拆装必裂 |
| C4 | **USB / SD 开口留 ≥0.6 mm 单边余量** | FDM 打印孔径会缩 0.2~0.4 mm；余量不够插不进 |
| C5 | **模组正上方必须有散热栅格** | ESP32-S3 跑摄像头时发热明显，密闭腔体会降频 |

## 三、外壳方案：三段式

```
        ┌──────────────────────────────┐
        │  上盖（阶梯状，2.5 t）        │  ← 摄像头视窗 + LCD 视窗 + 散热栅格
        ├──────────────────────────────┤
        │  中框（侧壁 2.5 t，无开孔）    │  ← 承力件，四个 M2.5 铜柱座
        ├──────────────────────────────┤
        │  底板（2.5 t）                │  ← Micro-USB 开口 + SD 开口 + 三脚架螺母位
        └──────────────────────────────┘
```

**为什么是"上盖 + 中框 + 底板"三段，而不是上下两半扣合？**

- 两半扣合要在侧壁做卡扣，而 Micro-USB 与 SD 卡必须开在侧壁附近 → **卡扣与开孔打架**（约束 C3）；
- 三段式把**开孔全部收到上下盖板上**，侧壁（中框）成为一根完整的封闭环 ——
  它是整个结构的承力件，四个铜柱座都做在它上面，**开孔一根都不碰它**；
- 拆装只需要拧 4 颗 M2.5 螺钉，不需要拆卡扣，反复拆装不磨损。

**装配顺序**（详见 §7）：底板 → 铜柱 → 主板/子板 → FPC → 中框 → 上盖。

**图纸**：[`hardware/enclosure_top.svg`](hardware/enclosure_top.svg) —— 顶视图，含全部开孔位置与外形尺寸。

## 四、结构方案：高度尺寸链

整机高度是一层层叠出来的，必须算清，否则会出现"上盖压住摄像头"或"整机虚高"：

| 层 | 厚度 (mm) | 累计高度 (mm) | 说明 |
|---|---|---|---|
| 底板 | 2.5 | 2.5 | 承力 + 三脚架螺母座 |
| M2.5 铜柱 | 5.0 | 7.5 | 支撑板卡，留出走线空间 |
| 主板 / 子板 PCB | 1.6 | 9.1 | 板卡上表面 |
| 摄像头模组 | 6.0 | **15.1** | 仅前段有 |
| 装配间隙 | 0.5 | 15.6 | 防压 |
| 上盖（前段） | 2.5 | **18.1** | 整机总高（前段） |
| LCD 模组（后段） | 3.2 | 12.3 | 后段基准 |
| 装配间隙 | 0.5 | 12.8 | 防压 |
| 上盖（后段） | 2.5 | **15.3** | 整机总高（后段） |

**台阶高度差 = 18.1 − 15.3 = 2.8 mm**（约束 C2 的来源）。

**图纸**：[`hardware/enclosure_side.svg`](hardware/enclosure_side.svg) —— 侧视剖面，含尺寸链与三条约束。

## 五、载板 PCB 方案

### 5.1 定位：不重画主控，只做电源与扩展

ESP32-S3-EYE 的核心板已经包含主控、摄像头、麦克风、SD、按键、LCD —— **重新画一遍没有任何收益**，
反而要重做阻抗控制、天线净空、Octal PSRAM 走线。所以载板只做三件事：

| 功能块 | 器件 | 解决什么 |
|---|---|---|
| **引出** | 2 × 1×20P 排母（对接 MB / SUB）+ 4P 端子台 | 排针引到端子台，外部传感器不用飞线 |
| **供电** | USB-C 输入 + SS34 反接保护 + 1 A 自恢复保险 + TP4056 + JST-PH 2P 电池口 + 电源开关 | 既能插电跑，也能接电池脱机跑（本项目实测过充电宝脱机） |
| **扩展** | I2C 4P JST 插座 + AO3400 低边开关 + 续流二极管 + 电源/状态 LED | 为「加陀螺仪」「驱动补光 LED」留插座，不用改核心板 |

### 5.2 关键布线规则

- **中间走线区（核心板正下方）禁止放高元件**，高度 ≤1.0 mm —— 否则与核心板背面短路；
- 走线只走 6 类：`3V3` / `5V` / `GND` / `SDA` / `SCL` / `UART_TX` / `UART_RX`；
- **I2C 的 SDA/SCL 必须与核心板上的 QMA7981 同一条总线**（都是 GPIO4/5）——
  这是本项目踩过的坑：摄像头 SCCB 抢总线导致加速度计全挂，
  载板扩展 I2C 时**必须复用电总线，不能新开一条**；
- 低边开关的续流二极管必须紧靠负载端子，否则关断瞬间的尖峰会打穿 MOS。

### 5.3 物料清单（BOM）

| 位号 | 器件 | 规格 | 数量 |
|---|---|---|---|
| J1 | USB-C 母座 | 16P 贴片，5 V 输入 | 1 |
| SW1 | 拨动开关 | SS-12D00 | 1 |
| U1 | 充电管理 | TP4056 模块或贴片方案 | 1 |
| J2 | 电池座 | JST-PH 2P（3.7 V 锂电） | 1 |
| D1 | 肖特基 | SS34（反接保护） | 1 |
| F1 | 自恢复保险 | 1 A | 1 |
| J3 / J4 | 排母 | 1×20P，2.54 mm | 2 |
| J5 | 端子台 | 4P，5.08 mm | 1 |
| J6 | I2C 扩展 | JST 4P（GND/3V3/SDA/SCL） | 1 |
| Q1 | MOSFET | AO3400（低边开关） | 1 |
| D2 | 续流二极管 | SS34 | 1 |
| LED1/2 | 指示灯 | 红 / 绿，0805 | 2 |

## 六、材料与工艺

### 6.1 外壳（3D 打印）

| 参数 | 取值 | 理由 |
|---|---|---|
| 工艺 | FDM | 打样快、成本低 |
| 材料 | **PETG**（首选）/ ABS（备选） | 摄像头模组周围会长期受热，PLA 会软化变形 |
| 层高 | 0.16 mm | 卡扣与螺纹孔精度够用 |
| 壁厚 | 2.5 mm（= 6 层 @0.4 喷嘴） | 与约束 C3 一致，保证中框承力 |
| 填充 | 25% 网格 | 无需更高 |
| 支撑 | 上盖台阶处需要 | 打印后必须清干净，否则压不住板 |
| 公差补偿 | **孔径 +0.3 mm，外形 −0.2 mm** | 补偿 FDM 收缩 |

### 6.2 载板 PCB

| 参数 | 取值 |
|---|---|
| 层数 / 厚度 | 2 层 / 1.6 mm |
| 表面处理 | 沉金（ENIG） |
| 最小线宽/间距 | 0.2 / 0.2 mm |
| 铜厚 | 1 oz |

## 七、装配顺序

1. **底板**：装入 1/4"-20 三脚架螺母（热熔嵌入或卡槽固定）；
2. **铜柱**：4 颗 M2.5×5 拧入底板；
3. **载板**：套在铜柱上，拧 4 颗 M2.5×4 固定；
4. **核心板**：主板与子板分别插到载板的两排排母上（**注意方向防呆，别插反**）；
5. **FPC**：连接主板与子板的 FPC 排线，**先接再压盖**（接反了盖不上）；
6. **中框**：套上，靠四个铜柱座定位；
7. **上盖**：对准视窗后压下，拧 4 颗 M2.5×8 贯穿螺钉。

> **装配检查点**：第 4 步之后**先通电验证**（摄像头、加速度计、SD 都正常）再继续装壳 ——
> 装完壳才发现板子插反，要全部拆开。

## 八、验证清单

打样前必须逐项过一遍，任何一项不通过都不许开模/打印。

### 8.1 打样前（图纸阶段）

- [ ] ★ 全部实测尺寸已替换，图纸里**不再有任何 ★**
- [ ] 摄像头光心与视窗圆心对齐（偏差 ≤0.5 mm），**66.5° 视场无任何遮挡**
- [ ] Micro-USB 插头可插到底，插拔 10 次不刮壳
- [ ] MicroSD 卡可完全插入并弹出，手指能捏到卡
- [ ] 6 个按键全部可按下并回弹，行程 ≥0.3 mm
- [ ] 4 个铜柱座与板卡安装孔同轴（偏差 ≤0.3 mm）
- [ ] 上盖台阶高度 = 18.1 / 15.3，与 §4 尺寸链一致

### 8.2 装配后（实物阶段）

- [ ] 整机拧紧后**无翘曲**，四角同时着地
- [ ] 连续插拔 USB 20 次，壳体无裂纹（验证约束 C3）
- [ ] 拆装 5 次，卡扣/螺纹孔无滑牙
- [ ] 三脚架拧上后整机稳固，镜头水平

### 8.3 功能与热

- [ ] 装壳后摄像头正常出图（`/api/frame/latest` 有画面）
- [ ] 装壳后加速度计读数正常（**验证载板 I2C 没有抢总线**）
- [ ] 连续跑 30 分钟周期抓拍，模组区域温度 < 70 ℃，无降频掉帧
- [ ] 电池供电脱机运行 ≥1 小时，充电红灯按预期亮灭
